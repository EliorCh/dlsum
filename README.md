# סיכום — למידה עמוקה

מדריך ויזואלי אינטראקטיבי בעברית לקורס ״למידה עמוקה״ (פרופ׳ ראיד סעאבנה, המכללה האקדמית תל אביב־יפו), שיעורים 0–1.

- **יסודות**: מודל הלמידה, מושגים, שיטת 7 צעדים וכלי gradient descent
- **שיעור 0**: פרספטרון, הכללה ו-overfitting, ייצוג ו-LLM, מנוירון לרשת
- **שיעור 1 · fastai**: צינור מלא, DataBlock, בחירת מודל ותרגיל 1
- **שיעור 1 · ממאפס**: רגרסיה ב-PyTorch, California housing, learning rate, סיווג, וקטוריזציה
- **תרגול**: מלכודות נפוצות, תרגיל חדש ושאלות חזרה

אתר סטטי. העיצוב, התפריט והכותרת התחתונה נטענים מהמאגר `main` המשותף.
