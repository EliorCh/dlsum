# סיכום — למידה עמוקה

מדריך ויזואלי אינטראקטיבי בעברית לקורס ״למידה עמוקה״ (פרופ׳ ראיד סעאבנה, המכללה האקדמית תל אביב־יפו), מאורגן לפי נושאים:

- **1 · מודל הלמידה ושיטת הפתרון**: ארבעת הרכיבים של כל תרגיל, מושגים, אותו מודל בארבע תצוגות, ושיטת 7 הצעדים עם כלי gradient descent.
- **2 · מהנוירון לרשת**: הפרספטרון של רוזנבלט, רגרסיה לוגיסטית, רשת משני נוירונים ופונקציות הפעלה.
- **3 · הכללה, דאטה וייצוג**: underfitting, הכללה ו-overfitting, הטיות בדאטה, ומה קורה לטקסט בתוך LLM.
- **4 · fastai**: צינור מלא מאיסוף תמונות ועד אימון, DataBlock פרמטר אחרי פרמטר, בחירת מודל ותרגיל 1.
- **5 · אימון נוירון ממאפס**: רגרסיה וסיווג שנכתבים ביד: MSE, גרדיאנט, צורות, learning rate, סיגמואיד ווקטוריזציה.
- **6 · PyTorch**: טנזורים וממדים, dtype, view, GPU, גרף חישוב ו-autograd, nn.Sequential ולולאת אימון.
- **7 · חזרה ותרגול**: מלכודות נפוצות, תרגיל חדש בסגנון הקורס ו-12 שאלות חזרה עם תשובות.

אתר סטטי. העיצוב, התפריט והכותרת התחתונה נטענים מהמאגר `main` המשותף.
