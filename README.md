# סיכום — למידה עמוקה

מדריך ויזואלי אינטראקטיבי בעברית לקורס ״למידה עמוקה״ (פרופ׳ ראיד סעאבנה, המכללה האקדמית תל אביב־יפו), מאורגן לפי נושאים:

- **1 · מודל הלמידה ושיטת הפתרון**: ארבעת הרכיבים של כל תרגיל, מושגים, אותו מודל בארבע תצוגות, ושיטת 7 הצעדים עם כלי gradient descent.
- **2 · מהנוירון לרשת**: הפרספטרון של רוזנבלט, רגרסיה לוגיסטית, רשת משני נוירונים ופונקציות הפעלה.
- **3 · הכללה, דאטה וייצוג**: underfitting, הכללה ו-overfitting, רגרסיה פולינומית, הטיות בדאטה, ומה קורה לטקסט בתוך LLM.
- **4 · fastai**: צינור מלא מאיסוף תמונות ועד אימון, DataBlock פרמטר אחרי פרמטר, בחירת מודל ותרגיל 1.
- **5 · אימון נוירון ממאפס**: רגרסיה וסיווג שנכתבים ביד: MSE, גרדיאנט, צורות, learning rate, סיגמואיד ווקטוריזציה.
- **6 · PyTorch: טנזורים ו-autograd**: טנזורים וממדים, dtype, view מול עותק, כפל מטריצות, GPU, גרף חישוב ו-autograd, והמלכודות שלו.
- **7 · PyTorch: בניית רשת ואימון**: nn.Module ושכבות, קונבולוציה, Dropout, Loss ואופטימייזרים, Dataset ו-DataLoader, לולאת אימון, וארבע רשתות מלאות מהמחברות: Iris, דיור, ו-MNIST עם MLP ו-CNN.
- **8 · סינון שיתופי ומערכות המלצה**: פירוק מטריצה בדוגמת Netflix עם כלי אימון, שכנים ודמיון, הטיות ו-SGD, משוב מרומז, NeuMF ומדדי הערכה.
- **9 · חזרה ותרגול**: מלכודות נפוצות, תרגיל חדש בסגנון הקורס ו-23 שאלות חזרה עם תשובות.

אתר סטטי. העיצוב, התפריט והכותרת התחתונה נטענים מהמאגר `main` המשותף.
