פתרון מודרך: רגרסיה עם נוירון יחיד, ממאפס

עכשיו בלי fastai: כל רכיב נכתב ידנית ב-PyTorch. זה התרגיל שהכי חשוב לדעת לשחזר, כי כל השאר (8 תכונות, סיווג) הם וריאציות שלו. בתרשים: דאטה סינתטי שבנינו באותו מתכון כמו בשקף 4 (20 נקודות סביב ישר, עם רעש), ואימון עם אותם lr ואתחול כמו בשקף 10; המספרים בתרשים חושבו בהרצה אמיתית.

השאלה (שקפים 2–12)נתונות 20 נקודות (x, y) עם x בין −2 ל-2. ממש ב-PyTorch נוירון יחיד ŷ = w·x + b, פונקציית MSE ולולאת gradient descent, ואמן אותו.
צעד 1: הדאטה
np.random.seed(42)x = torch.linspace(-2, 2, steps=20)[:, None]y = add_noise(f(x), 0.15, 1.5)

x הוא 20 מספרים, y הוא ערך הפונקציה עם רעש. זה D.

צעד 2: משפחת ההיפותזות

כל ישר y = w·x + b הוא היפותזה. המחלקה net היא המשפחה: המבנה קבוע, והפרמטרים _w, _b פתוחים.

1class net:2def __init__(self):3torch.manual_seed(42)4self._w = torch.randn(1)5self._b = torch.randn(1)6def forward(self, x):7return self._w * x + self._b
צעד 3: נקודת התחלה

n = net() מגריל w = 0.3367 ו-b = 0.1288. אפשר לבדוק: n.forward(2) מחזיר 0.3367·2 + 0.1288 = 0.8022. ואם נשים ידנית n._w = 5; n._b = -2, אז n.forward(2) מחזיר 8 (שקף 6).

צעד 4: כמה טעינו

הקווים הכתומים הם השאריות y − ŷ. ה-MSE הוא ממוצע הריבועים שלהן:

def mse(preds, acts): return ((preds-acts)**2).mean()
L = (1/N) Σ (yᵢ − (w·xᵢ + b))²

בנקודת ההתחלה שלנו L = 9.33.

צעד 5: גזירה

בשקף 9 גוזרים עם SymPy את L לפי w ולפי b. ממוצע על כל הנקודות נותן:

∂L/∂w = −(2/N) Σ xᵢ (yᵢ − ŷᵢ)
∂L/∂b = −(2/N) Σ (yᵢ − ŷᵢ)

בהתחלה dw = −6.642: שלילי, ולכן הורדת lr·dw מגדילה את w, והישר מסתובב למעלה (החץ האדום).
